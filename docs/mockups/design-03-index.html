Design 03 variant sheets

One page per layout decision in docs/design-03-sidebar-and-attention.md. Each page has two or three variants switchable at the top, on the same data (eight projects, three pinned, threads in every state), drawn with the app's own markup and tokens. Rows, project names, tiles and controls react to clicks. Every variant's note says which logged problem it closes.
