Where should the Open in VS Code button sit on a chat?

Each option below shows the top of the main pane for the same chat, once when it runs in a worktree and once when it runs in the project folder. Hover the VS Code logo to see its tooltip.

In every option the button opens the folder the chat is actually in: the worktree when there is one, the project folder when there is not. The dots menu does not get the item, since the button sits right beside it.

Option A

A VS Code logo button beside the dots

One icon button with the VS Code logo, just left of the dots. It is the same button the project page already has, so it looks familiar. Look at: the right end of the header.

What stays the same in every option

If you use Cursor, Windsurf or VS Code Insiders instead, the button shows that editor's logo and name. If the chat's folder has been deleted, the button is greyed out with the tip "Folder not found". If no editor is installed, there is no button. Shells get the same button, opening the folder the shell is in.
